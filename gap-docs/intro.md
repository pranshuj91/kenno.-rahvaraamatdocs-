# Gap Documents

This area is **separate from Developer Docs**. It tracks documentation gaps for the Rahva Raamat ecommerce backend.

## Fill policy (no bluffing)

- If matching content exists under `/docs`, the gap page is **filled by copying that content**.
- If no matching content exists, the gap page stays **Not Documented** and only registry metadata is shown.
- Source file paths are listed on each filled page.
