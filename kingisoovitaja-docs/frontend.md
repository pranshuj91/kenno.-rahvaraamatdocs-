# Website (Frontend)

- Location: `frontend/`. Next.js `^16.4.2`, React 19, zustand, zod, Tailwind, react-markdown.
- Brought into this repo with its history (git subtree, FE ADR-0008). The old `kingisoovitaja-v2` repo is no longer developed.
- Built as a standalone Docker image (`node:24-alpine`, port 8080). `NEXT_PUBLIC_*` values are build arguments.
- Runs as its own compose project (`frontend/compose.yml`) that reads this repository's `.env`.

## BFF API routes (Next.js server)

`/api/chat` (SSE to the browser), `/api/chat/feedback`, `/api/conversations`, `/api/products`, `/api/products/[id]`, `/api/gift-extras` (calls `/precart.php`), `/api/checkout`, `/api/stores`, `/api/parcel-machines`, `/api/health`.

The browser never calls the PHP backend. The Next.js server calls `http://backend-api:8081`. The backend does not stream: the BFF wraps its answer as SSE for the browser.

## Backend selection

- `CHAT_BACKEND=live` calls `BACKEND_API_URL=http://backend-api:8081`.
- `BACKEND_MOCK_FALLBACK=true` answers missing calls with sample data (**must be `false` in production**).
- With `GIFT_ADVISOR_API_URL` set, checkout goes to the e-shop (see [E-shop API & Checkout](./eshop-api-checkout)).

## Language and feature flags

- Estonian dictionary only (`et.ts`); `en` and `ru` fall back to Estonian.
- Flags: voice input, conversation history, feedback (`NEXT_PUBLIC_ENABLE_*`). Feedback is on by default on origin/main.
- The landing page links to theme pages are hardcoded in `frontend/src/lib/config/landing-content.ts`; the products come from the backend.

## Frontend ADRs (`frontend/docs/adr/0001` to `0010`)

Framework, BFF, checkout, state, gift bags and cards, live backend without streaming, checkout on kingisoovitaja, self-hosted container, product pages and the Gift Advisor API from the BFF.

## Frontend docs folder

`frontend/docs/` holds numbered documents: flow map, tech stack and hosting, pages/components/states, user flows, API contract (`04-api-contract.md`), chat UX, non-functional requirements, blocked-by-design decisions (`07`), estimates. `frontend/PROJECT_STATUS.md` is generated by `scripts/update-status.mjs` and must not be edited by hand.
